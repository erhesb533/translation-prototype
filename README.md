# Орчуулгын платформ — ярилцлагын прототип

Монголд орчуулгын захиалга өгөх/гүйцэтгэх онлайн платформын санааг **харилцагчийн ярилцлага дээр
үзүүлэх, дарж үзэх боломжтой прототип**. Бүтээгдэхүүн биш. Дэлгэрэнгүйг [`SPEC.md`](SPEC.md)-ээс.

- React + Vite + TypeScript, **backend-гүй** — бүх өгөгдөл mock, хөтчийн `localStorage`-д.
- Бодит төлбөр, бодит файл боловсруулалт, машин орчуулгын API **байхгүй**.
- Бүх нэр, компани, орчуулагч **зохиомол**. Үнэ бол **жишээ**.

## Дэлгэцүүд

| # | Дэлгэц | Зам |
|---|--------|-----|
| 1 | Нүүр — үнэ цэнийн санал, хэлний хос, түвшин | `#/` |
| 2 | Захиалга өгөх — mock файл, хэл, түвшин, хугацаа → шуурхай үнийн санал | `#/order` |
| 3 | Захиалгын төлөв — хүлээн авсан → орчуулж байна → хянаж байна → бэлэн, татах | `#/status` |
| 4 | Компанийн (B2B) самбар — захиалгууд, сарын нэхэмжлэх, нэр томьёо | `#/business` |
| 5 | Орчуулагчийн самбар — ирсэн ажил, хүлээн авах, хугацаа, орлого | `#/translator` |
| 6 | Ярилцлагын горим — баруун доод буланд **🎤 Ярилцлага** товч | бүх дэлгэц дээр |

Урсгалууд холбоотой: захиалга өгөхөд тэр нь орчуулагчийн самбарт "ирсэн ажил" болж харагдана;
орчуулагч хүлээн авахад захиалгын төлөв "Орчуулж байна" болно. Компани сонгож өгсөн захиалга
компанийн самбарт нэмэгдэнэ. Төлөвийн дэлгэц дээрх **"Дараагийн шат руу (демо)"** товчоор явцыг гараар ахиулна.

## Ажиллуулах

Node.js 20+ хэрэгтэй.

```bash
npm install
```

```bash
npm run dev
```

Хөтчөөр `http://localhost:5173` нээнэ. Утсаар үзэх бол (ижил Wi‑Fi):

```bash
npm run dev -- --host
```

Терминал дээр гарах `Network:` хаягийг утсаараа нээнэ.

Бусад тушаал:

```bash
npm run build    # dist/ хавтаст production build
npm run lint     # oxlint
npm test         # Vitest (үнийн тооцоо + үндсэн урсгал)
npm run preview  # build-ийг локалд үзэх
```

## Үнийн тохиргоог ярилцлагын үеэр өөрчлөх (`src/pricing.ts`)

Бүх үнэ нэг файлд: [`src/pricing.ts`](src/pricing.ts). Файлын дээд хэсэгт байгаа тоонуудыг л засна:

| Тогтмол | Утга |
|---------|------|
| `TIER_RATES` | Нэг үгийн үнэ: `mtpe` (машин + хүний засвар), `human`, `notarized` |
| `NOTARY_FEE_PER_DOCUMENT` | Нотариатын нэмэлт төлбөр, нэг баримт тутамд |
| `DEADLINES` | Хугацааны сонголт: хоног ба үржүүлэгч (`1.3` = +30% яаралтай нэмэгдэл) |
| `MINIMUM_ORDER` | Хамгийн бага захиалгын дүн |
| `B2B_DISCOUNT` | Компанийн хөнгөлөлт (`0.1` = 10%) |
| `VAT_RATE` | Нэхэмжлэхийн НӨАТ |
| `TRANSLATOR_PAY_PER_WORD` | Орчуулагчийн самбарт харагдах нэг үгийн хөлс |

Ярилцлагын дундуур:

1. `npm run dev` ажиллуулсан байлгана.
2. `src/pricing.ts`-ийг засварлагчаар нээж, жишээ нь `human: 150` → `human: 130` болгоод хадгална.
3. Хөтөч **автоматаар шинэчлэгдэнэ** (hot reload) — нүүр, захиалгын үнийн санал, самбарууд шинэ үнээр гарна.
   Бөглөсөн маягт хадгалагдахгүй байж болох тул жишээ файлаа дахин сонгоно.

Ярилцлагын JSON экспорт тухайн үед харуулсан үнийн тохиргоог (`pricingShown`) хамт хадгалдаг тул
аль ярилцагчид ямар үнэ үзүүлснийг дараа нь харьцуулж болно.

> GitHub Pages дээрх хувилбарт үнэ өөрчлөхийн тулд `pricing.ts`-ийг засаад `main` руу push хийнэ — workflow дахин deploy хийнэ (1–2 минут).

## Ярилцлагын горим ба тэмдэглэл татах

1. Аль ч дэлгэцийн баруун доод буланд **🎤 Ярилцлага** товчийг дарна.
2. Ярилцагчийн **код** (жишээ нь `Х-07`, бодит нэр бичихгүй), сегмент (B2C / B2B / Орчуулагч)
   оруулаад **"Ярилцлага эхлэх"**. Товч улаан болж кодыг харуулна.
3. Дэлгэц бүр дээр харилцагч **1–5** оноогоор хэр хэрэгтэйг үнэлж, тэмдэглэл бичнэ. Самбар нь
   одоо нээлттэй дэлгэцийг автоматаар сонгоно; өөр дэлгэцийг дээд талын товчоор сонгож болно.
4. **LOI-д гарын үсэг зурах сонирхол**: Тийм / Магадгүй / Үгүй ба ерөнхий тэмдэглэл.
5. **"Ярилцлага дуусгах"** — дараагийн ярилцагч руу шилжинэ.
6. **"⬇ JSON татах"** — бүх ярилцлагыг `yariltslaga_YYYY-MM-DD-HH-MM.json` файлаар татна.

Тэмдэглэл **зөвхөн тухайн төхөөрөмжийн хөтчийн `localStorage`-д** хадгалагдана (сервер рүү
явахгүй). Хөтчийн өгөгдөл цэвэрлэх, incognito цонх хаахад устана — ярилцлага бүрийн дараа JSON татаж
хадгалахыг зөвлөе.

JSON бүтэц:

```json
{
  "exportedAt": "…",
  "summary": { "interviews": 12, "loiYes": 3, "loiMaybe": 4, "averageRatings": { "order": 4.3 } },
  "pricingShown": { "TIER_RATES": { "mtpe": 90, "human": 150, "notarized": 150 } },
  "sessions": [
    { "code": "Х-07", "segment": "B2B", "ratings": { "home": 4 }, "notes": { "home": "…" },
      "loi": "yes", "generalNote": "…", "startedAt": "…", "endedAt": "…" }
  ]
}
```

Демо өгөгдлийг (захиалга, нэр томьёо) цэвэрлэх бол хөтчийн DevTools → Application → Local Storage
дээрх `tp.orders`, `tp.jobs`, `tp.glossary` түлхүүрийг устгана. Ярилцлагын тэмдэглэл (`tp.interviews`)
тусдаа тул **"Устгах"** товчоор л арилна.

## GitHub Pages-д байршуулах (идэвхжүүлэх алхам)

Workflow бэлэн байгаа: [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). PR дээр зөвхөн
lint + тест + build шалгана; `main` руу push хийх эсвэл гараар ажиллуулахад deploy хийнэ.
Pages-ийг нэг удаа идэвхжүүлэх шаардлагатай:

1. GitHub дээр repo → **Settings** → зүүн цэсний **Pages**.
2. **Build and deployment** → **Source** хэсэгт **"GitHub Actions"**-ийг сонгоно.
3. Энэ PR-ийг `main` руу merge хийнэ (эсвэл **Actions** → **Build & deploy to GitHub Pages** →
   **Run workflow**).
4. Workflow дуусмагц (1–2 мин) **Settings → Pages** дээр хаяг гарна:
   `https://<хэрэглэгчийн-нэр>.github.io/translation-prototype/`.
5. Repo private бол Pages нь GitHub-ийн төлбөртэй багцад л ажиллана — тэгвэл repo-г public болгох
   эсвэл ярилцлага дээр `npm run dev -- --host`-оор локалаас үзүүлнэ.

Чиглүүлэлт нь hash (`#/order`) ба `base: './'` тул repo-гийн нэр өөрчлөгдсөн ч нэмэлт тохиргоо
хэрэггүй. Тогтмол зам хэрэгтэй бол build хийхдээ `BASE_PATH=/repo-нэр/ npm run build`.
